# Kayfabe v1.0.1

First published GitHub release. Includes the scanner, agent-assisted triage workflow, offline regression corpus and benchmark documentation currently on `main`.

## Recent changes

- **MCP file confinement:** reject directory-junction and symlink escapes in code reads, searches and triage evidence validation. Reads use bounded file descriptors and identity checks. Portable race and hard-link limitations remain documented in [FILE-CONFINEMENT.md](../FILE-CONFINEMENT.md). (#29)
- **C# SQL precision:** recognize a narrow class of cross-file literal `const string` interpolations in `CommandText`. Unknown bindings, mutable values, inherited classes and unsupported syntax retain warnings. (#30)
- **GitHub release updates:** check for newer stable releases and install an exact release tag after confirmation, with Git configuration isolated and package lifecycle scripts disabled. (#28)

## Verification and limits

- Combined Linux CI passed **479 tests**, with no failures or skips, and **190 vulnerable/fixed regression pairs** before release preparation. Release-version CI is required before tagging.
- The latest detector change has zero scoring-unit transitions across all seven established benchmark suites: no lost true positives or new false positives. These measurements retain their frozen source identities and policies; the version bump does not change detection logic.
- On the new safe-only C# apps, raw false-positive warnings fell **2 → 1**. The labeled case rate remains **1/20 (5%)** because the removed warning was outside the labeled ranges. The remaining MVC controller warning needs framework-aware binding.
- The supplied set is development evidence with prior scanner exposure. It contains no vulnerable cases and measures no recall. Native C remains unsupported and receives no true-negative credit.
- The original real-CVE pair score remains **0/8**; a separately localized policy scores **1/8**. Regression results do not establish production detection accuracy.

See [CONST-MEMBER-SQL.md](../CONST-MEMBER-SQL.md) for the detector scope, comparison tables and frozen evidence, and [MCP-CONFINEMENT-SELF-AUDIT.md](../MCP-CONFINEMENT-SELF-AUDIT.md) for the self-audit.

## Install or update

Requires Node.js **20 or later**, plus Git and npm for global installation. No runtime dependency installation is needed when running directly from source.

Existing global installations:

```sh
kayfabe update
```

Fresh global installation from the release tag:

```sh
npm install --global --ignore-scripts 'git+https://github.com/ray-goldman/kayfabe.git#v1.0.1'
```

Source checkouts must be updated separately. The `appsec` command and existing MCP tool names remain compatibility aliases.
